# 产品需求基线

## 1. 初始化与家庭作用域

用户通过 `npm run db:init` 创建空白家庭空间，然后建立账户、资产目录和第一笔流水。所有家庭业务数据必须带 `familyId`，VIEWER 只能读取。

验收基线：

- 未初始化时页面给出明确引导，而非静默创建演示数据。
- 当前成员只能看到所属家庭数据。
- 会话切换、写操作和关键系统动作进入审计链。

## 2. 账本与现金闭环

用户可以录入、CSV 导入、筛选、导出和冲正流水。证券买卖可通过账户配置生成同币种现金结算腿。

验收基线：

- BUY/SELL 金额等于数量乘单价，禁止超卖。
- DEPOSIT/WITHDRAW 只能作用于现金资产。
- VALUATION 只用于房产或手动估值资产。
- 冲正保留原记录、标记 `voidedAt`、创建 REVERSAL，并联动作废结算腿；不物理删除历史。
- 内部结算腿和转账不计入外部净投入。

## 3. 财富与持仓

系统重放有效流水，按账户和资产形成持仓，再按实时行情、官方净值、手动估值、面值或成本回落估值。

验收基线：

- 剩余成本采用移动平均成本法。
- 净资产 = 总资产 − 总负债。
- 可自由投资 = 现金与可交易组合资产；房产、手动估值资产和华为员工持股不进入该口径。
- 外币资产按当前 USD/CNY、HKD/CNY 汇率折算展示；成本和市值使用同一当前汇率，价格盈亏不夹带汇率波动。
- 页面能说明价格来源与估值新鲜度。

## 4. 行情与基金估值

默认行情链为腾讯、天天基金、Sina。PriceBar 保存历史价格；场外基金历史只保存官方净值，盘中估值另表保存并可用官方净值校准。

验收基线：

- 真实链失败不得回落模拟价；`simulated` 仅在显式配置的 E2E/离线环境使用。
- 基金今日官方净值公布后使用官方值；未公布且具备新鲜输入时可展示内部估值，并标明 `FUND-ENGINE`。
- `FundEstimate` 不覆盖官方 `PriceBar`；`FundCalibration` 保留估算与官方结果的误差。

## 5. 绩效、风险与看盘

看盘页提供组合当日盈亏、盘中曲线、区间收益、TWR、XIRR、最大回撤、波动率、夏普与四个基准指数对比。

验收基线：

- TWR 消除外部出入金影响；XIRR 表达资金加权年化。
- 无新行情、休市和纯资金流快照不能伪装成新的收益观察点。
- 历史曲线显示估值状态、覆盖率和缺口，而不是假装数据完全结算。

## 6. FIRE、储蓄与配置

目标支持一次性目标和退休现金流模式。FIRE 模拟同时评估积累达标和退休后不断供；储蓄记录、收益/波动假设参与情景分析。

验收基线：

- 目标可以使用净资产或可自由投资口径。
- 模拟结果可复现，使用确定性种子和协方差建模。

## 7. 运维与可恢复性

本地、生产、E2E 使用独立 Next dist 目录；E2E 使用独立种子数据库。支持 SQLite 一致性备份、恢复前自动备份和 Docker/腾讯云部署。
