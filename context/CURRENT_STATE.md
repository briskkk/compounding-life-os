## 已知限制与风险

1. 行情与基金端点依赖外部免费服务，存在限流、格式变化和暂时不可用风险；外币组合在实时与历史真实汇率均不可用时会明确失败。
2. `PriceBar`、`RateBar`、`FundEstimate`、`FundCalibration`、`User`、`Session`、`Invite` 是全局共享数据，不带 `familyId`，不得误套家庭 RLS。
3. SQLite 与 PostgreSQL 使用独立 schema；CI 已验证 PostgreSQL 建表和 RLS 契约，但真实生产迁移仍需在目标环境做备份、行数核对与回滚演练。
