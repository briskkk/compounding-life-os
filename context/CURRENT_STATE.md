# 当前项目状态

更新时间：2026-08-24

## 版本与分支

- 包版本：`0.1.0`
- 当前分支：`main`
- 当前 lockfile 栈：Next.js 15.5.20、React 19.2.7、strict TypeScript、Prisma Client 6.19.3、SQLite/PostgreSQL、Vitest、Playwright

## 已实现

- 交易账本重放、移动平均成本、已实现/未实现盈亏、冲正与现金联动结算。
- 账户、资产、负债、储蓄、目标、快照、审计模型。
- 净资产与可自由投资双口径；华为员工持股独立长期资产分类。
- 腾讯/天天基金/Sina 真实行情链、基金盘中估值、官方净值历史和误差校准。
- TWR、资金加权（Modified Dietz 逐日链式）、XIRR、区间绩效、最大回撤、波动率、夏普、基准对比和估值质量状态。
- FIRE 积累/不断供模拟与确定性蒙特卡洛情景分析。
- 九个一级页面（含组合复盘与设置）、账户/资产详情、CSV 导入导出、备份恢复、Docker 与腾讯云部署脚本。
- 应用层家庭作用域、VIEWER 只读、PostgreSQL RLS 脚本和 SHA-256 审计链。

## 最近完成

- 安全与恢复边界：写 API 只接受真实用户会话，全局 Key 降为只读；Session token 入库改存 SHA-256（兼容旧 token 渐进迁移）；登录、注册和邀请加入增加速率限制。SQLite 备份统一使用 `.backup` 一致快照、quick_check、行数校验和原子改名，新增服务器备份/恢复入口。
- 基金交易闭环：基于上交所官方公告内置 2024–2026 休市日历；预估净值交易可在官方净值公布后一键冲正并重建结算腿；申购、赎回、分红、利息和费用的现金联动语义统一。
- CSV 批次导入：新增 `ImportBatch` 内容指纹、来源文件、金额/费用对账和流水反向追溯；同一文件重复提交不再重复入账。
- 长历史与行情增量：快照和单资产绩效从首笔流水完整回放，取消 1400 天静默截断；行情刷新会补早期缺口、只覆盖实际返回区间、增量更新尾部，并对连续故障 provider 短时熔断。
- 外汇可复现性：外币组合按需使用 ECB 官方日度参考汇率交叉计算 USDCNY/HKDCNY 并回填缺口，不覆盖已有新浪真实记录；资产详情移除固定汇率常数。
- APP API 契约：`POST /api/transactions` 支持 `Idempotency-Key`，同键重放不重复记账、同键异体返回 409；流水、审计和已保存复盘支持游标分页，新增本期复盘证据包 API。
- 生产可观测与 PG 契约：`/api/health` 增加数据库、快照、备份、审计链和维护任务诊断；PostgreSQL 搬迁清单覆盖全部 20 个模型并校验行数，CI 使用真实 PostgreSQL 16 建表、施加 RLS 并验证跨家庭读写拒绝。
- 审计链并发安全：同一家庭的业务写入与审计追加使用进程内串行事务；`AuditLog.chainScope + chainKey` 数据库唯一约束阻止同一父哈希产生两个后继，多实例冲突时整笔事务重试。普通业务唯一键冲突不会被误重试，无家庭归属的系统审计也受同一协议保护。
- 汇率按需加载：总览、看盘、复盘、绩效/报价 API 与快照重建仅在组合含 USD/HKD 时加载真实/历史汇率；纯人民币组合使用单位折算，不访问外部汇率源或 `RateBar`，避免无关外部故障阻断页面与快照。
- 行情源正确性加固：`MARKET_PROVIDER` 空值/未知/重复配置明确失败，只有显式 `simulated` 才能启用模拟行情；报价补齐真实数据时点、接收时点、数据类型及实时/延迟/陈旧/休市/未知语义。固定外汇常数回落已移除，新浪失败只使用 `RateBar` 最后一笔真实汇率并标记陈旧，且不会冒充今日新浪数据。缓存支持同标的并发合并，健康状态跨模块共享，`/api/health` 始终列出配置链与汇率降级状态。
- 桌面 Web 排版基线：Web 明确定位为 1280px 及以上桌面财富终端，手机体验由独立 App 承担；九个一级页面完成 1280/1440px 巡检，顶栏主导航保持单行，核心财务数字不拆行。收益日历的日/月/年、页脚合计、柱图提示与当日明细统一显示带千分位和两位小数的完整人民币金额，不再使用“万/亿”缩写。
- 组合周期复盘（ADR-014）：新增 `/review` 本周/本月/本季度视图，按标的/来源/资产类别对账利润与亏损，回看有效收益日、主动交易及集中度/现金/外币/估值缺口变化；资产金额与多期 TWR 贡献百分点分别守恒，未归属残差作为“待对账差额”独立展示，真实赎回在途资金另列为资产状态，不混入贡献排名。新增 `PortfolioReview` 家庭表保存用户草稿/完成状态与证据快照，受 VIEWER 只读、RLS 和审计链保护；不恢复自动建议层。

## 已知限制与风险

1. 行情与基金端点依赖外部免费服务，存在限流、格式变化和暂时不可用风险；外币组合在实时与历史真实汇率均不可用时会明确失败。
2. `PriceBar`、`RateBar`、`FundEstimate`、`FundCalibration`、`User`、`Session`、`Invite` 是全局共享数据，不带 `familyId`，不得误套家庭 RLS。
3. SQLite 与 PostgreSQL 使用独立 schema；CI 已验证 PostgreSQL 建表和 RLS 契约，但真实生产迁移仍需在目标环境做备份、行数核对与回滚演练。
