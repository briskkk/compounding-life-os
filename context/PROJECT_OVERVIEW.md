# 项目概览

## 定位

Family Wealth OS（界面默认品牌“家庭财富终端”）是一个自托管的家庭财富操作系统。它以交易流水为唯一事实源，统一管理账户、资产、负债、财富轨迹、投资绩效、目标测算和审计记录。

它不是普通收支记账工具，也不是券商交易终端。产品核心是把分散的家庭资产转化为可追溯、可解释、可行动的财富视图。

## 目标用户

- 希望在本地或自有服务器集中管理多账户、多币种、多资产家庭财富的个人或家庭。
- 重视数据所有权、计算口径和审计可追溯性的长期投资者。
- 需要同时观察总家底、可投资资产、风险暴露和退休目标的人。

## 核心价值

- 可追溯：持仓、成本、净投入和快照由流水重放推导。
- 双口径：同时展示净资产与可自由投资资产，避免房产、长期内部持股污染投资组合判断。
- 真实行情：生产默认接真实行情链；失败时保留缺口或按成本估值，不伪造市场价格。
- 决策支持：用 TWR、XIRR、回撤、波动率、夏普和账本驱动的目标测算形成解释性提示。
- 数据主权：本地 SQLite 开箱即用，可迁移至 PostgreSQL，数据保存在自有环境。

## 当前产品表面

Web 以家庭任务组织为总览、资产、投资、记录、复盘、目标六个一级入口；持仓、账户、看盘、流水、定投、月结与治理继续使用既有路由，并通过二级工作流和全局搜索进入。退休压力测试位于目标页高级区域。

Web 界面定位为家庭财富工作台，默认浅色，以 1280px 及以上视口为正式验收范围；移动端体验由独立 App 提供，Web 的窄屏兼容只作兜底。

## 当前阶段

项目处于可运行、可自托管的 `0.1.0` 阶段。核心账本、估值、绩效、复盘、目标测算与退休压力测试、行情、审计、备份与部署路径已实现；账号密码认证、多家庭、邀请协作、快照增量重建与双 schema 自动一致性门禁已完成。移动端体验由独立 APP 承担（见 `docs/mobile-app/APP_PLAN.md`）；Web 正按 ADR-035 分阶段迁移到家庭财富工作台，见 `CURRENT_STATE.md`。

## 明确不做

- 不连接券商执行真实交易或自动下单。
- 不把模拟行情混入真实生产数据。
- 不维护可直接编辑的持仓或余额表。
- 不把量化提示包装成确定性的投资建议。
- 不在本仓库开发移动端 APP（独立项目，通过 `/api/*` + Bearer token 对接）。
