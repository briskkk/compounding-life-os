# 资产详情公开产品资料

从持仓列表进入单个资产详情，可查看基金/ETF公开持仓与公告，使用“刷新产品资料”重新读取。该面板保留，组合穿透与风险图谱、投资策略实验室已按用户要求移除，见 [ADR-042](adr/042-remove-research-modules.md)。

持仓显示报告期、来源、取得日期、覆盖范围和来源限制；公告显示日期、标题与原文链接。境内基金/ETF使用东方财富公开摘要及定期报告，支持的境外ETF使用明确发行商产品注册表。联接/FOF仅显示报告实际披露的基金投资行，不递归计算家庭组合暴露。资料不代表实时仓位或全市场覆盖。

页面按来源顺序最多显示前10项持仓，超过时明确提示；总项数及已披露比例按完整资料计算，可通过持仓来源链接查看原文。

持仓缓存六小时、公告十五分钟；失败保留上次成功资料及时间，不把读取失败显示为确认无持仓或无公告。公开缓存独立存放在 .cache/product-information，不含家庭账户、金额、份额或流水。未确认代码、报告表差异及境外公告缺口按产品提示。

资料接口先验证当前家庭资产归属。刷新仅取得公开产品资料，不写流水、审计、家庭披露或策略记录，不参与持仓余额、估值或收益计算。没有新增后台任务或商业数据订阅。
