# 投资日报图片

网页入口：投资 → 投资日报（`/watch/daily`）。生成北京当天的只读投资记录，支持刷新预览、复制图片、保存 PNG；Web 与 CLO Desk 共用 `GET /api/desktop/daily-report` 的真实家庭会话数据。

## 图片与交互

- 默认 1080×1440，纸白、宋体中文、Times New Roman 优先的衬线数字、细分隔线。沿用用户选定的[设计稿](design/investment-daily/reference.png)及 CLO Desk 最终渲染器的尺度与配色。工作台本身继续使用 ADR-046 的字体和双主题。
- 顺序：当日盈亏/收益率、组合当日盈亏分时曲线、正收益金额 TOP 5、其余持仓收益、今日买卖；“今日操作”标题旁汇总买入金额，只加总当日记录的买入，不扣减卖出；没有买入时不显示该汇总。名称换行，多笔操作增高；超过单张图片安全高度 16000px 时明确报错，不截断。
- 不显示操作时间、净资产、账户、份额或成本。保留必要估值状态、部分行情覆盖和跨日归属提示；模拟行情显式标注。设计示例仅在 E2E fixture 中，生产没有示例数据兜底。
- 预览和导出绑定同一份快照，导出前用轻量 tasks 接口核对用户/家庭。刷新、失败、会话变化均清除旧图；竞态响应不能恢复失效快照。VIEWER 可预览与导出。
- 复制需要浏览器的图片剪贴板支持及授权，失败可保存 PNG；所有绘制使用本地字体与 Canvas，无跨站截图服务。中文提供本地托管的 Noto Serif SC Variable 后备字体（SIL OFL，依赖内附许可证）。

## 数据边界

- 汇总复用 `buildDesktopGlance` / `observeLivePortfolio`，不重新定义当日收益率、归属日或估值覆盖。
- 正收益资产跨账户合并后按收益金额降序取前五，不足五项显示实际项数；其余持仓为总收益减已显示收益，保持分币对账。
- 曲线复用现有分钟行情和 `buildIntradayCurves`，只接受匹配报价场次的分钟点；汇总报价用于末点。缺分钟的成员沿用现有看盘的常量贡献口径。没有可用曲线或末点无法与汇总对账时显示“暂无分时数据”。
- 操作来自北京当天、截至生成时点的真实 BUY/SELL 流水，排除冲正、内部腿和关联结算腿；金额按现有汇率转 CNY。按用户要求，分享图片及其无障碍描述不显示“待确认”，接口和账本继续保留 pending 状态。图片不包含流水时刻或私有账户字段。
- Cookie/Bearer 真实会话、家庭作用域、private/no-store；不接受全局 API Key，无 schema、余额、账本或快照写入。详细接口见 [桌面 API](desktop/API.md)。

## 验证

2026-11-27：750 项单测、生产构建、207 项完整隔离 E2E 通过；覆盖真实会话、匿名/失效拒绝、家庭切换、VIEWER、收益对账、PNG 下载与尺寸、复制的 PNG Blob、失败重试、空行情、长名称/30 笔操作、深浅主题及 560/1280/1440/1600/1920px。

另在本机浏览器的隔离种子库实测复制成功，读取到 `image/png` 剪贴板内容，控制台无错误。视觉比较与证据见根目录 [design-qa.md](../design-qa.md)。示例导出含“演示数据”，不代表用户实际投资结果；不将 Mac 原生保存面板或剪贴板当作 Web 验收结果。
