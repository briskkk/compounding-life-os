# ADR-003：同时维护净资产与可自由投资口径

## 状态

Accepted（“手动估值资产”规则由 ADR-015 部分替代）

## 决策

净资产包含全部资产并扣除负债；可自由投资只包含现金和可交易组合资产。房产、华为员工持股及手动估值的非黄金资产计入家底，但不进入可投资、看盘和组合收益体系。GOLD 恒表示可交易黄金，即使使用手动估值也进入可投资组合，详见 ADR-015。

## 原因

家庭偿付能力与投资组合调度能力回答不同问题。混用会夸大可配置资本并污染风险和 FIRE 判断。

## 后果

页面、目标和测试必须明确使用哪一口径；新增资产类别时必须明确其归属。
