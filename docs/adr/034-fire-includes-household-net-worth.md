# ADR-034：FIRE 纳入员工持股等长期资产，使用家庭净资产口径

## 背景

ADR-033 曾规定退休目标只使用可自由投资资本，排除房产、华为员工持股和其他长期资产。用户随后明确要求 FIRE 纳入员工持股等长期资产，因此需要替代该资本边界，同时保留目标测算的简化信息架构。

## 决策

1. `STREAM` 退休目标统一使用 `NET_WORTH` 作为当前资本：纳入员工持股、房产及其他长期资产，并按净资产定义扣除当前负债。
2. `LUMP_SUM` 普通财富目标继续允许用户选择 `NET_WORTH` 或 `INVESTABLE`。
3. 既有退休目标即使保存为 `INVESTABLE`，读取和投影时也按 `NET_WORTH` 计算；不在读取时静默改库，用户明确保存目标后才同步持久化口径。
4. 净资产包含缺少可交易组合模型的长期资产，因此 FIRE 投影不套用可投资组合的资产类别协方差模型，而使用目标中明确保存的综合年化收益与波动假设。页面必须同时披露长期资产金额、负债、估值日期、估值覆盖和模型来源。
5. 纳入只改变目标规划的资本起点，不让员工持股或房产进入可投资组合、看盘、TWR、XIRR或资产配置计算，也不生成交易。

## 后果与限制

- FIRE 数值会显著高于只使用可投资资本时的结果；它表达家庭总财富支持退休的能力，不等于资产可以立即变现。
- 当前投影把净资产作为一个整体应用综合收益/波动假设；员工持股的兑现限制、房产处置成本、税费和未来负债变化仍需在高级假设或人工判断中单独考虑。
- 若未来只希望纳入部分长期资产，应新增明确的 FIRE eligibility 或可实现比例，而不是再次混用可投资口径。

## 验证

- 单测覆盖退休目标从既有 `INVESTABLE` 记录切换到 `NET_WORTH`，以及普通目标保持用户选择。
- 页面与表单明确显示“家庭净资产”“含长期资产并扣负债”和“综合资产手工假设”。
- API、网页与移动端继续共用同一目标资本选择函数。
