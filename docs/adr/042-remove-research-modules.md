# ADR-042：移除组合穿透与策略实验室，保留资产公开资料

## 背景与替代范围

用户明确要求删除组合穿透与风险图谱、投资策略实验室，认为没有实际可用度。本决定替代 ADR-039 的正式研究模块，以及 ADR-040、041 中的组合递归分析、账户冻结实验和家庭研究保存条款。用户此前要求的资产详情产品持仓与公告仍保留。

## 决策

1. 删除两模块的页面、域导航、全局搜索项、研究查询/保存接口、专属组件及计算/服务代码，不重定向到其他分析页。
2. 资产详情继续按资产家庭归属读取公开产品持仓、报告期、来源和公告。公开资料的契约移动到市场适配层，不依赖研究引擎，也不运行组合图谱或实验。
3. 保留 ADR-040、041 的公开来源、实际权重校验、独立公开缓存、错误与成功资料时间显示、只发送公开产品代码等边界。未知身份不猜测，权重不归一化，不把产品资料写为家庭财务事实。
4. 已应用的研究迁移与两张旧表保留，标记为停用档案；没有业务读取或写入入口。保留其家庭隔离、RLS、备份/搬迁兼容，不删除历史记录或修改账本。
5. 家庭财务规划仍暂缓。原路线图、任务包和静态原型只作为历史设计，不能视为继续实施这两个模块的授权。ADR-021 的长期复盘与可选证据解释仍有效，当前不提供正式策略实验室。

## 验收

- 持仓域四项、复盘域六项入口；全局搜索不再出现两模块。
- 认证后的原页面与 GET/POST 研究接口返回 404。
- 资产详情仍显示产品持仓/公告并可刷新；跨家庭资料请求返回 404。
- 全量单元测试、生产构建和隔离 E2E 通过；真实账本和旧研究表不写入。
