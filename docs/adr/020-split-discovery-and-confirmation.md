# ADR-020：拆分发现与核对入账

## 状态

Accepted。延续 ADR-018 的事件证据与账本分离，不引入第二份余额。

## 决策

- 行情刷新、现有本地行情任务及公司行动页可检查境内 ETF / 基金的公开拆分表。来源仅为发现线索，不能将表中的折算日猜作除权日。未支持的标的及网络/解析失败明确显示。
- 检查结果以家庭审计链 `SPLIT_SCAN` 保存。检查不更改交易；当前不自动抓取并解释所有发行人公告，不连接券商账户。
- 境内 ETF 正向拆分支持核对入账：用户提供官方公告链接、除权日和券商新增份额；系统使用登记日原始账本份额核算，差额、日期间交易和已有事件冲突均停止。场外基金、缩股、尾差及复杂权益事件仍用人工公司行动。
- 通过核对后生成 `CorporateAction` 和 `SHARE_ADJUSTMENT`，不改现金及总成本。家庭、账户、资产、登记日构成稳定请求键，由数据库唯一约束及审计事务防止重复入账；已冲正事件不能自动重放。
- 前复权全历史行情必须覆盖已有缓存以及除权日后数据，才能与事件一并提交。按完整账本重建快照。当前覆盖验证不代表已自动核实所有供应商复权因子；行情异常应保留待核对。
- 登记日权益计算先截断原始交易，不能复用图表为了前复权而换算的历史份额；除权日新买入不参加此前登记日的拆分。

## 验证

解析格式失败、网络错误留证据、差额拒绝、VIEWER/家庭隔离、同日新增买入、并发幂等及成本/现金守恒测试；页面检查入口验收。
