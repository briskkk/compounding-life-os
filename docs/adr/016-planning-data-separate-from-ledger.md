# ADR-016：配置目标与未来现金安排属于计划层，不进入交易账本

## 状态

Accepted。

## 背景

产品需要回答两个与历史事实不同的问题：当前资产配置离家庭自己设定的目标有多远，以及未来某月有哪些确定或计划中的资金流。若把目标权重、预算或提醒写成交易，会污染持仓、净投入、收益率与审计语义；若把当前持仓复制成可编辑余额，又会形成第二账本。

## 决策

1. `AllocationTarget` 保存家庭自定义的资产大类目标权重与容忍带。当前权重和偏离金额始终由实时可投资资产派生；在途赎回资金按现金计入，房产和长期资产排除。
2. `CashPlan` 保存未来流入、流出或里程碑，可选一次、每月、每年重复和关联账户。它是计划事项，不计入现金余额、净资产、投入或收益。
3. 资金日历把 `CashPlan` 与交易账本派生的赎回在途到账合并展示；在途事项不可在计划层删除，到账后随账本状态自动消失。
4. 配置偏离只陈述“高于目标、低于目标、范围内”和差额，不生成自动买卖建议，不自动创建流水。
5. 两类计划记录均受家庭作用域、VIEWER 只读、PostgreSQL RLS 与审计链保护。

## 后果

- 用户可以规划和观察，但真实余额与收益仍只有交易账本一个事实源。
- 删除计划事项只删除未来安排，不会撤销或改动任何交易。
- 目标配置变更可追溯，但历史偏离图若需要长期留存，应以后从快照与审计记录派生，不新增可写配置余额。

## 验证

- 单测覆盖目标偏离、在途归入现金、重复现金事项展开与月度净额。
- E2E 覆盖健康中心、目标保存、资金计划新增和移除。
- 双 schema、家庭作用域与 PostgreSQL RLS 清单保持一致。
