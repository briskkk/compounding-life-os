# ADR-009：LLM 只承担可选解释层

## 状态

Superseded，已被 [ADR-011](011-remove-insights-advice-llm.md) 取代：LLM 层已随洞察、建议功能整体移除。

## 决策

财务事实、指标和规则判断由本地确定性代码计算。LLM 只接收脱敏聚合上下文，输出经 Zod 校验并记录模型、prompt 版本和快照时间；无模型时系统完整降级到规则引擎。LLM 不得写账本或自动下单。

## 原因

财富数据要求可复现、可审计和最小披露，生成模型不适合承担事实计算或不可逆动作。

## 后果

模型输出必须与证据分离；新增 AI 功能必须有权限、隐私、失败和结构校验测试。
