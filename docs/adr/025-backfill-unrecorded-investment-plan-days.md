# ADR-025：漏录的到期定投日不能被较晚买入掩盖

## 背景

快速录入原先只列出最近一次匹配 BUY 之后的计划节点。真实账本中 2026-09-15 已有买入而 2026-09-14 没有，导致 9/14 从快速录入消失，用户不能从定投管理页补录该日实际发生的申购。

## 决策

1. 快速录入候选日期改为计划窗口内所有已到期且同日没有匹配有效 BUY 的节点，不以最近一次 BUY 作为下限。较晚日期的买入不代表较早计划日已经执行。
2. 同日已有匹配 BUY 的节点仍不提示再次录入；提交时服务端继续逐笔查重、校验账户/基金/计划日期，并整批原子写入。
3. 逐日执行视图中可快速录入的待核对日期直接链接到对应日期的勾选表单。未实际买入的基金保持不勾选，不生成流水；当前没有独立的“已核对未执行”持久状态。
4. ADR-024 的用户确认、金额/费用/净值日核对、`PENDING` 与现金结算、家庭权限及审计边界均不变。

## 兼容与验证

- 不迁移、不修改现有计划或交易记录；只改变待核对日期列表与页面导航。
- 单测覆盖较晚 BUY 存在时较早漏录日仍显示、同日已有 BUY 排除。
- E2E 使用隔离账本复现 9/15 已买而 9/14 未录，从计划日链接进入表单并核对后录入。
