# ADR-019：场外基金份额未知时先记录申购事件

## 状态

Accepted；修订 ADR-012 中“净值未知则拒绝落库”的录入约束。

## 背景

场外基金通常按金额申购。当晚复盘时，用户已经知道申购日、金额和资金划出，但官方成交净值与确认份额可能尚未公布。强制当时填份额会造成伪精确；拒绝记录又会让当日操作从账本与复盘中缺失。

## 决策

1. 场外基金 `BUY` 允许在只已知正数申购金额和 `navDate` 时写入；`quantity` 与 `price` 保持 `null`，`navSource=PENDING`。
2. 待确认申购必须生成关联现金结算腿。申购金额由账本重放派生为“申购待确认资产”，计入净资产和可投资资产；费用仍即时减少净资产。
3. 待确认金额不进入持仓份额、成本、收益贡献或可卖份额；复盘将它作为资产状态单列。
4. 取得官方净值后，沿用冲正链作废原 `PENDING` 流水及现金腿，再用原申购金额、官方净值和折算份额写入正式 `BUY`。
5. 不新增可写状态表；待确认视图完全由有效流水派生，仍遵守账本唯一事实源。

## 兼容性与回滚

- 不新增数据库字段；`Transaction.quantity` / `price` 已允许为空，`navSource` 为字符串。
- 旧 `OFFICIAL` / `ESTIMATE` 流水行为不变。回滚功能时只需停止创建 `PENDING` 流水；已有记录仍可冲正或确认。

## 验证

- 单测覆盖待确认视图、现金与净资产守恒、非基金拒绝、必须现金联动和官方净值替换。
- 页面验收覆盖无净值时仍可按金额保存、流水待确认标记和日复盘交易回看。
