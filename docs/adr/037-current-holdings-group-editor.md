# ADR-037：分组编辑只列当前持仓

## 背景

ADR-036 让结构分析页同时列出当前持仓和有历史流水的已清仓资产。资产逐渐增多后，已清仓资产会挤占日常分组整理列表，也让用户难以确认正在调整哪部分组合。

## 决策

1. 结构分析页的“整理资产分组”只列账本重放后仍有持仓的可投资资产，与该页持仓/结构视图使用同一持仓集合；无持仓的历史资产及尚未交易的资产不出现在编辑列表。
2. 编辑列表的范围不限制分类复盘。已清仓资产的历史流水仍参与其所属分类的历史收益，资产详情和收益历史保留既有入口。当前分类仍追溯应用于历史，按 ADR-036 计算，不保存分类快照。
3. 分类复盘按维度和具体分组分层选择，默认进入当前持仓的自定义组合分组；若无此类分组，优先进入有持仓的非现金资产大类。分组候选仅来自有交易流水的可投资资产，避免选择后没有收益证据的空分类。

## 数据、兼容与回滚

- 不迁移、不删除资产、分类、目标或流水；只是编辑入口与复盘选择器的展示范围变化。批量保存、家庭作用域、权限与审计沿用 ADR-036。
- 既有 `/review/groups?scope=...&period=...` 深链保持有效；已清仓资产所属组仍能从复盘中选择。若旧深链指向无交易资产的分类，回退到默认可复盘分类。
- 回滚只需恢复编辑列表和分类选择器，不影响已有数据。

## 验证

- 浏览器验证结构页仅列当前持仓、批量保存和分类维度/分组/周期切换及深链。
- Vitest、生产构建和 Playwright 全量回归。
