# ADR-041：公开持仓统一接入、实际权重递归与独立归档

> 2026-10-10：由 [ADR-042](042-remove-research-modules.md) 替代。组合递归与家庭分析条款已撤回；公开产品来源、实际披露校验和独立缓存仍用于资产详情。

## 背景及替代

用户要求完善境外 ETF、联接和 FOF 的底层权重缺口，并已允许以公开产品代码读取东方财富。此决策扩展 ADR-040 第 1、4 条的境内摘要和进程缓存限制；账本、家庭保存及实验规则继续遵守 ADR-039、040。商业数据源可以后续接同一契约，本次不购买或接入付费服务。

## 决策

1. `ProductInformation` 统一承载产品持仓、报告期、首次取得日期、来源、公告及独立错误。境外 ETF 使用明确产品注册表接发行商 JSON/XLSX/CSV，核对 ticker/CUSIP/工作表身份；境内摘要与公告仍来自东方财富，定期报告正文来自其公告转载接口。
2. 联接目标必须同时取得报告内目标主代码和目标投资表独立权重；FOF 基金表必须明确净资产分母。只按精确产品名称或报告内代码匹配，不将基金总仓位配给目标 ETF，不猜 UCITS 份额。未知身份保留报告行键和权重，不发送猜测代码。
3. 全股票表核对完整表标记、产品身份、报告期、净资产分母、代码及权重数量，并对同报告期摘要交叉验证。股票和基金两表同时存在时合并，不被小额基金投资表降级回前十大。未支持的 ISIN 映射或表格差异保留摘要和明确错误。
4. 自动递归只读取有据基金引用，最多 80 个产品、六并发、五层；引擎继续检测循环并逐层相乘。不同层报告期有提示，每个根产品的缺口按金额列出路径、原因和报告期。
5. `ALL_REPORTED` 表示采用来源可核对的全表项目，不能等同净资产 100%；`FULL` 仍要求净权重恰好为 100%。保留有据负现金/其他抵项，拒绝空头股票或基金。超限全表若股票合计有效则保留全部股票、非股票及舍入余量待核；否则降为前十项。绝不归一化、用指数代理或把衍生品名义价值转成股票暴露。
6. 公开资料独立写入 `PRODUCT_INFORMATION_CACHE_DIR`，默认 `.cache/product-information`，含最后成功版本、按报告期/内容哈希的版本与原始来源字节。首次取得日期不能因重新获取相同版本而前移。目录忽略 Git，不含家庭、账户、金额、份额、交易或登录信息，不自动保存 `ExposureDisclosure` 或审计记录。
7. 公告十五分钟、持仓六小时、错误一分钟后可重试，手动刷新可跳过缓存。失败保留成功资料及其取得时间，不以空列表冒充成功。尚无后台定时任务、历史穿透查询或统一行业分类。
8. 外部下载限固定 HTTPS 主机及同主机重定向，文件最大 8 MB、工作表解压最大 12 MB，拒绝 XML 实体。两家发行商在当前 Node 传输环境中拒绝连接，使用无 shell 的 Python urllib 兼容传输；Docker 镜像包含 Python。未安装 Python 则回退 Node 并明确来源失败，不伪造持仓。

## 兼容与运行

无新数据库迁移，旧 JSON 披露仍可读取；用户预检保存发行商预览时登记为用户确认的证据，不冒充自动原文核验。Docker 增加独立公开缓存卷；SQLite 备份不包含该卷，可独立备份或重新读取公开源。回滚适配器不修改家庭财务事实。

## 验证

身份/日期/净资产分母、换行与重复序号、股票和基金表合并、未知基金不串行错配、负现金金额守恒、超限全表降级、XML/重定向边界、持久缓存和失败保留；页面缺口与底层来源、跨家庭和 VIEWER 权限、预览不写账本。实际验证与完整测试记录于 CURRENT_STATE。
