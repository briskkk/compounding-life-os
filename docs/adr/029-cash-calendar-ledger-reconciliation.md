# ADR-029：资金日历作为计划与账本的按日核对视图

## 状态

Superseded by [ADR-031](031-cash-calendar-ledger-activity-only.md)。本 ADR 保留为历史决策记录。

## 背景

原资金日历只展示 `CashPlan` 与赎回在途到账，无法回答某天计划投什么、实际买卖了什么、真实买入是否匹配定投计划。页面还用当前现金叠加整月计划推算月末现金，容易把已经反映在当前余额里的当月事项再次计算。

## 决策

1. 资金日历同屏展示四类证据：手工现金计划、定投计划节点、有效 BUY / SELL 流水、赎回在途到账。
2. 定投节点仍属于计划层；BUY / SELL 只从未作废、非内部结算腿的交易账本读取。关联只表示账户、候选资产与计划窗口匹配，不声称计划自动触发交易。
3. 每日月历只显示分类摘要，选中日期后展示逐项证据；真实买卖可下钻到按日期和类型过滤的流水页，定投节点可回到同月定投核对页。
4. 首屏分别展示计划金额、实际买入、实际卖出与节点核对状态，不再用当前现金加减整月事项推导“月末计划后现金”。
5. 跨币种月度汇总按当前汇率折算人民币，并明确只用于同屏比较；逐项证据保留原币金额。

## 后果

- 资金日历成为计划—执行—现金结果的统一入口，但不会形成第二账本或自动生成交易。
- 用户可从日期直接核对真实 BUY / SELL；无效或冲正流水不会出现。
- 历史跨币种汇总不是历史汇率口径，精确历史绩效仍以复盘引擎为准。

## 验证

- 纯函数测试覆盖四类事件合并、计划与实际分账、节点状态和计划匹配。
- E2E 覆盖指定日期的真实买入展示与按日流水下钻。
