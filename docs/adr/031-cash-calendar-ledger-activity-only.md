# ADR-031：资金日历只呈现真实账本活动

## 状态

Accepted。用户于 2026-09-22 确认提交并交付资金日历的账本活动口径。本 ADR 替代 ADR-029。

## 背景

ADR-029 把手工现金计划、定投计划节点、实际买卖与赎回到账放进同一月历。该设计虽然能同屏核对计划和执行，但月度合计同时包含未来计划与已成交流水，无法直接回答“本月实际买了多少、卖了多少”，计划事件也会占据本应表达已发生事实的日格。

手工资金计划和定投计划已有各自的维护与核对入口，不需要依赖资金日历承载。

## 决策

1. 资金日历只展示未作废、非内部结算腿的有效 BUY / SELL 流水，以及由账本派生的赎回到账在途。
2. 手工 `CashPlan` 回到账户概览维护，不进入日历格或日历月度合计。
3. 定投计划节点继续在定投管理页核对，不进入日历格；实际 BUY 可以标注匹配到的定投计划，但该关联不把计划变成交易。
4. 月度摘要只展示实际买入、实际卖出、赎回到账在途的金额与笔数，不再推导计划净额或月末现金预测。
5. 逐项事件保留原币金额；人民币月度汇总沿用页面当前汇率，只用于同屏比较，不替代历史绩效口径。

## 后果

- 资金日历明确回答“账本里实际发生了什么”，计划与事实不再混排。
- 资金计划维护入口移到账户概览，定投核对入口保持在定投管理页。
- 真实买卖仍可按日期和类型下钻到流水，赎回在途可下钻到卖出流水。
- 本变更不新增流水、余额、快照或第二账本，也不改变任何计划的执行状态。

## 验证

- 纯函数测试覆盖买卖方向与金额、赎回在途、跨月剔除、同日排序、定投关联标注、空输入和非法月份。
- E2E 覆盖资金计划在账户概览维护、计划不进入日历，以及实际买卖按日展示与流水下钻。
- 生产构建与 TypeScript 检查必须通过。
