# ADR-035：Web 改为家庭财富工作台，并按六项家庭任务组织导航

## 背景

现有 Web 已覆盖账本、持仓、看盘、复盘、目标、定投和治理，但一级侧栏同时容纳日常查看、记录操作与低频维护。用户需要记住“某个工具在哪”，总览也把家庭净资产、可投资资产变化和当日行情放在相近层级，增加了口径理解成本。

2026-09-28 的三页高保真候选验证了新的方向：浅色家庭财富工作台、家庭财富与投资表现分区、待办直达、持仓表格优先，以及定投按实际执行核对。用户已明确认可并要求继续完成设计和启动开发。

## 决策

1. Web 默认使用浅色“家庭财富工作台”，深色保留为用户可选主题。1280px 及以上仍是正式桌面验收范围，窄屏继续作为可用兜底。
2. 一级导航收敛为六项家庭任务：总览、资产、投资、记录、复盘、目标。它们分别承接多个既有路由，不迁移 URL，也不改变数据模型。
3. 数据健康、基金确认、账户对账、公司行动、导入批次、审计和设置保留为可搜索、可深链的二级工作流；数据异常仍可从全局数据入口直达。
4. ADR-033 关于目标测算的计算、证据和高级压力测试决策全部保留；仅替代其“目标退出一级侧栏”条款。目标重新成为一级任务，因为它是家庭财富工作台的核心决策问题。
5. 视觉层级按“结论 → 解释 → 证据”组织。家庭净资产、可自由投资资产和负债必须明确分区；投资收益必须标明可投资口径、周期和估值证据。
6. 新风格不得改变账本、计划、行情、绩效、家庭作用域和审计语义。待核对不等于未执行；计划不生成流水；部分、在途、缺失、待确认与已确认必须保持可区分。
7. 迁移按壳层与 token、总览、资产、投资、记录、复盘与目标、治理页面六批实施。每批独立验收，避免一次性重写全部页面。

## 导航映射

| 一级任务 | 默认路由 | 归属路由 |
| --- | --- | --- |
| 总览 | `/` | `/` |
| 资产 | `/positions` | `/positions/*`、`/accounts/*`、`/allocation` |
| 投资 | `/watch` | `/watch`、`/review/returns` |
| 记录 | `/transactions` | `/transactions/*`、`/investment-plans` |
| 复盘 | `/review` | `/review`、`/review/history`、`/review/decisions`、`/month-close` |
| 目标 | `/goals` | `/goals` |

## 兼容与回滚

- 不修改 Prisma schema、流水、快照、目标、计划、审计和 API。
- 既有路由与深链全部保留；仅调整入口、样式和页面信息层级。
- 主题 cookie 继续使用 `portfolio-theme`。没有 cookie 时默认浅色；既有明确选择深色的用户继续使用深色。
- 回滚可恢复旧导航和默认主题，不影响任何财务数据。

## 验证

- 单测守卫主题 token、字号、语义色与导航映射。
- E2E 覆盖六项一级导航唯一高亮、命令面板键盘顺序、目标一级入口和治理工作流可发现性。
- 1280、1440、1600、1920px 检查核心金额不截断；560–1100px 检查页面级无横向溢出。
- 每个迁移页面覆盖空、部分、错误、只读、长名称和大金额状态。
