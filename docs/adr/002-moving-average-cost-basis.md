# ADR-002：持仓成本采用移动平均法

## 状态

Accepted

## 背景

系统需要稳定、易解释且适合聚合家庭账户的剩余成本和已实现盈亏口径。

## 决策

BUY 将成交额和费用加入剩余成本；SELL 使用卖出前 `costBasis / quantity` 释放成本并计算已实现盈亏。原币保存成本，展示时与市值使用同一当前汇率折 CNY。

## 后果

- 结果不等同 FIFO 或税务批次法。
- 改为其他成本法属于数据口径迁移，必须替代本 ADR 并重算历史。
