# ADR-040：自动获取产品资料，按明确范围运行实验

> 2026-10-10：由 [ADR-042](042-remove-research-modules.md) 替代。穿透页、账户实验与家庭保存条款已撤回；资产详情公开持仓/公告、报告期、缓存与外发边界仍有效。

## 背景

用户指出新功能“全是未知不可用”，并明确产品缺少及时获取持仓与公告的能力。真实库没有保存披露版本，全组合实验同时被待确认交易、公司行动和手工黄金估值阻断。用户明确允许向东方财富发送当前基金/ETF公开产品代码取得资料，不发送账户、金额、份额或流水。

## 决策

1. 穿透页按账本当前正持仓自动读取境内基金/ETF的公开持仓摘要和公告，资产详情使用同一资料能力。最多六个产品并发、外部请求五秒超时，仅发送公开产品代码。
2. 持仓报告期直接使用持仓报文 `Expansion`，替代 ADR-039 第1条首期摘要“报告期来自独立资产配置接口”的实现限制。证券、债券和行业来自实际披露；联接目标名称不等于实际权重，不使用 JJ 总仓位猜测目标ETF权重。
3. 自动资料用于明确标识的临时分析预览，不自动保存家庭披露，也不写审计或财务表。已有同报告期或较新的家庭版本优先；正式留存仍预检后显式确认。公告十五分钟缓存、持仓六小时缓存，可强制刷新；失败保留成功资料的时间与错误，不冒充空列表或新报告。
4. 未解析余量按根产品分别列示；报告期、取得时间、来源链接独立保留。首期尚无境外ETF、报告全文解析、后台归档或行业统一。
5. 允许单账户冻结实验，使用完整家庭账本核对结算关系，只有所选账户持仓/现金进入实际路径。跨范围结算作为范围外部资金进入冻结现金；提款不足仍失败，结果明确不代表全组合。
6. 默认本月；未指定范围且全组合阻断时，把可运行的最大账户及日期写入URL，标题、选择器、结果同时显示范围。明确选全组合时不自动切换；无范围可运行则保持阻断。公司行动、价格、权益及未确认订单限制在相关范围继续严格检验。
7. 保存参数新增可空 `accountId`，旧记录为全组合。查询、保存和复算都验证账户属于当前家庭；每条保存记录按自己的范围比较水位，不因查看范围变化而误称证据变化。

## 数据及兼容

迁移 `20261010090000_experiment_account_scope` 只向 `InvestmentExperiment` 添加可空文本字段，双schema同步。现有 family scope、RLS、整体搬迁、备份和审计保持不变。字段是历史参数引用；账户删除后保留记录并报告不可复算，不复制余额。升级前一致性备份，默认schema生成客户端并重启开发服务。

## 验证

- 实际持仓自己的报告期、市场身份、行业、债券；无权重不猜测。
- 公告失败与空列表区分，未来公告过滤，刷新失败保留成功资料。
- 账户实验不受无关交易影响，外部结算可追溯，提款不足不卖出。
- 保存明确范围、拒绝跨家庭查询；资料预览不写家庭财务表。
- 正式页面刷新、预览、来源链接、范围深链及保存的隔离浏览器验收。
