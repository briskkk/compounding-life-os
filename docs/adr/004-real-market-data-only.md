# ADR-004：真实环境不伪造市场价格

## 状态

Accepted

## 决策

默认沿腾讯、天天基金、Sina 优先链取真实数据。全部失败时返回缺口或以成本计值，不自动生成模拟价格。`simulated` 仅在环境变量中显式启用，主要供 E2E 和离线演示。

## 原因

伪造价格会让净值、盈亏、风险和决策提示看似完整却失真，代价高于明确显示缺数据。

## 后果

UI 必须展示来源和新鲜度；测试环境必须显式配置模拟源；刷新时清理遗留 SIMULATED PriceBar。
