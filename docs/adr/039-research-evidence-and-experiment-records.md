# ADR-039：穿透披露和策略实验保存研究证据，不建立第二账本

> 2026-10-10：由 [ADR-042](042-remove-research-modules.md) 替代。正式研究模块已按用户要求移除；旧表只作档案兼容。

## 背景

用户于 2026-10-09 要求暂缓家庭财务规划，启动组合穿透与风险图谱、投资策略实验室。已有基金画像没有可追溯的披露版本；个人反事实实验不符合 ADR-021 的正式模板。

本决策落实 ADR-001、014、017、021、022 与 027 的既有边界，不替代它们。

## 决策

1. `ExposureDisclosure` 是家庭内追加式披露快照。保存报告期、公开或取得日期、来源链接、覆盖范围、来源质量及占产品净资产的权重。用户录入与第三方摘要均不自动声称原文已核验；摘要报告期来自独立资产配置接口，需核对原文。
2. 当前暴露从真实账本正持仓估值派生。嵌套产品权重沿路径相乘，股票按市场和代码合并；未知余量、缺失披露、循环及超过五层的路径均归入未知。指数成分和估值代理不得代替实际持仓。现金透支及在途资金单独列示，不混入正持仓暴露分母。
3. 行业来自披露录入的分类证据；同证券的分类可复用，冲突保留未知。市场图谱只指证券上市市场，不推断公司收入地区、经济外汇风险、工资相关性或损失概率。
4. `InvestmentExperiment` 只保存名称、日期、冻结规则版本和账本/价格/汇率/资产元数据水位。打开已保存日期后按当前证据复算，并显示证据或规则是否变化。结果不写入 Transaction、Snapshot、PriceBar 或 RateBar。
5. 首期模板从期初收盘后持仓出发，忽略主动买卖及其费用；同一外部资金留在原币现金，同币提款现金不足即阻断。现金收益率假设为零；分红仅在账户份额一致、现金结算证据一致且未复权价格/官方单位净值口径明确时复用实际权益金额，期后分红回写前复权历史也须核验。无现金腿黄金交易按 ADR-015 的组合外资金流进入/离开冻结现金。
6. 公司行动仍应按 ADR-021 应用；首期尚未实现可核验的复权与权益配对，因此起点之后存在相关事件时严格阻断；起点之前已完成的拆股按拆股后实际持仓使用，不把忽略公司行动的计算发布为有效结果。同样阻断待确认交易、不明确转移、费用、缺失历史价格/汇率、超过七天的陈旧观测及未配对交易。沿用七天内前次观测标为部分证据，不标为完整每日收益。
7. 两张表受家庭作用域、VIEWER 只读和原子审计链保护。第三方资料先取得候选，用户预检并确认保存；不自动批量落库，不发出交易指令。

## 数据、兼容与回滚

- 新增迁移 `20261009090000_research_modules`；双 schema、RLS、SQLite→PostgreSQL 清理/搬迁/行数校验同步新增两模型。
- 本地升级前使用一致性备份；不修改既有账本和快照。完整 SQLite 备份天然包含两表。
- 回滚应用代码不会改变财务事实；保留新表可供再次升级。需要恢复旧备份时按既有停服恢复流程操作，再应用数据库迁移。
- 被忽略的个人 `counterfactual.ts` 保持原样，正式引擎为 `frozen-holdings.ts`。

## 验证

- 穿透守恒、嵌套/循环、未知、证券身份、权重分母和来源限制。
- 冻结起点、未来买入与未来价格隔离、提款不足、分红份额差异、公司行动、历史汇率、北京时间、期后到账和黄金外部资金。
- 保存不改财务表；家庭隔离、VIEWER 禁写与审计链完整性。
- 正式页面的日期深链、预检保存、有效/部分/阻断结果及浅深色桌面布局。
