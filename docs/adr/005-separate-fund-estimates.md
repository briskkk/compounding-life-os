# ADR-005：基金盘中估算与官方净值隔离

## 状态

Accepted

## 决策

官方历史净值保存为 `PriceBar`；盘中内部估算保存为 `FundEstimate`，报价来源标记 `FUND-ENGINE`；官方公布后切回官方值，并用 `FundCalibration` 保存误差。估算不得覆盖官方历史。

## 原因

两类数据的权威性、时间语义和可追溯要求不同。隔离后才能展示置信度、分析误差并保护历史绩效。

## 后果

基金实时页面需要解释数据来源；历史快照刷新只使用官方基金历史；存储和查询复杂度增加。
