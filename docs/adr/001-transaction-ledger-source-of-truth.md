# ADR-001：交易账本是唯一事实源

## 状态

Accepted

## 背景

持仓、成本、现金和绩效若分别维护可写余额，会在补录、冲正和内部结算时产生不可追溯差异。

## 决策

以 `Transaction` 为事实源；有效流水按时间重放生成持仓。Snapshot、持仓、净投入和绩效都是派生结果。错误记录通过冲正作废，不物理删除。

## 后果

- 所有数字可回溯至流水，历史时点可重算。
- 写操作更复杂，且流水变更需要刷新派生快照。
- 禁止新增可直接编辑的余额/持仓表绕过账本。
