# ADR-038：组合分组收益只选当前持仓资产

## 背景

ADR-037 将结构页分组编辑限制为当前持仓，但分类复盘仍把已清仓资产及只由它们构成的旧组合分组列入结果。用户在“组合分组”复盘中看到不属于当前组合的资产，分组目标和复盘范围因此不一致。

## 决策

1. “组合分组”以账本重放得到的当前持仓资产为成员。只由已清仓资产构成的分组不再作为候选；当前分组中的已清仓资产也不进入收益汇总和贡献明细。
2. 对仍持有的成员，继续用其完整交易与估值历史计算区间收益。筛选成员不修改交易或历史估值，也不把当时已卖出的份额伪装成当前持仓。
3. 分类复盘与收益历史对同一个组合分组使用相同成员集合，保持曲线、日历与复盘结果可对照。大类、风格、市场、标签维度继续允许回看已清仓资产的历史表现。

## 数据、兼容与回滚

- 无数据迁移；资产分组、目标与流水保持原样。当前持仓由账本推导，不增加可写余额。
- 旧深链若指向仅有已清仓资产的组合分组，分类复盘回到默认可用分类，收益历史回到完整组合。仍有当前持仓的深链保持有效。
- 回滚只需恢复分组候选及成员过滤；财务数据不变。

## 验证

- 单测覆盖“同组一项在持、一项清仓”与“旧组全部清仓”；确认其他分类仍能回看已清仓资产。
- 浏览器核对组合分组候选、资产贡献与收益历史深链，运行构建和回归。
