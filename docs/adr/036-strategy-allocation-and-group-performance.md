# ADR-036：互斥组合分组、可自定义配置目标与分类收益

## 背景

既有资产大类由账本决定，市场分组由代码与币种推导，风格是单一枚举，自定义标签可以重叠。资产大类目标只有固定类别，无法把同一大类拆成“A股宽基”“A股卫星”等自定义组合；结构页也不能直接整理分组。收益历史和复盘只提供全组合视角。

## 决策

1. 保留账本资产大类和自动市场归属作为事实口径，不允许为了策略目标改写已交易资产类别。风格和多标签仍可编辑；结构分析页提供直接编辑入口，覆盖当前持仓及有历史流水的可投资资产。
2. 为每项资产增加一个可为空的互斥 `strategyGroup`。空值显示为“未分组”。这套分组用于组合权重与目标，避免多标签重复计入比例。已有标签仍可交叉筛选，但不可相加成配置权重。
3. 家庭范围内的 `StrategyTarget` 保存用户自定义组名、目标权重和容忍带；目标权重合计必须为 100%。原有按资产大类的 `AllocationTarget` 继续独立工作。配置偏离仅作观察，不产生交易或修改账本。
4. 分类收益支持大类、风格、市场、互斥组合分组和标签。所选资产的历史持仓、价格、汇率与资金流由账本和估值数据逐日重放。当前分类应用到整个历史区间；改分组会重算历史，不保存“当时分组”的快照。
5. 分类复盘展示期初、期末、净投入、投资收益、TWR、风险与估值覆盖，并可下钻资产贡献和收益日历。完整组合复盘仍沿用原有权威口径；分类结果不可替代全组合结果，重叠标签也不可加总。
6. 配置及分类绩效只覆盖可投资资产；房产、员工持股等长期资产继续留在家庭净资产及退休目标边界内，不进入投资组合收益或配置。份额待确认申购归所属组，赎回在途暂列未分组。

## 数据与兼容

- `Asset.strategyGroup` 默认为空字符串，既有资产无需自动猜测分类；`StrategyTarget` 是家庭作用域表，加入 SQLite/PostgreSQL schema、迁移、RLS、初始化、恢复和 PostgreSQL 迁移路径。
- 分组编辑复用有权限校验与审计的资产更新动作；目标保存及清空追加审计。只读成员只能查看。
- 原有资产大类目标、历史收益 URL 和移动端持仓字段保持兼容；移动端持仓列表新增 `strategyGroup` 字段。
- 回滚界面与目标表不会影响交易账本；要停止使用自定义目标可直接在配置页清空，资产上的组名保持可重新启用。

## 验证

- schema 同步和迁移检查；纯函数验证互斥分组的目标偏离。
- 浏览器覆盖结构页分组编辑、目标保存与清空、分类复盘与收益历史、VIEWER 只读边界。
- TypeScript、Vitest、生产构建及全量 Playwright 回归。
