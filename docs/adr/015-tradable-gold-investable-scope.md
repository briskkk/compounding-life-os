# ADR-015：GOLD 恒为可交易、可投资资产，估值方式不决定资产口径

## 状态

Accepted。

## 背景

ADR-003 原先把所有 `manual=true` 资产排除在可投资组合之外。产品中的黄金均为可交易黄金，但当前黄金使用手动估值流水更新价格，因此被错误当成长期非流动资产，未进入可投资资产、流动性和周期复盘。历史上直接录入且没有现金结算腿的黄金买入，还会在纳入组合后把本金误算成收益。

## 决策

1. `AssetClass.GOLD` 在本产品中恒表示可交易黄金，始终进入可投资资产、看盘、流动性和组合收益体系。
2. `manual` 只描述估值来源，不再决定 GOLD 的资产口径；黄金仍可使用 `VALUATION` 手动更新总市值。
3. 房产、华为员工持股及其他手动非黄金资产继续排除在可投资组合之外。
4. 黄金 BUY/SELL 有 `settleOfId` 现金结算腿时是组合内部换仓，不改变外部净投入；历史黄金 BUY/SELL 没有任何结算腿时，按组合外转入/转出处理，避免本金被识别为利润。
5. 复盘组合曲线和标的曲线必须使用同一批价格、汇率和估值日期；赎回在途资金作为派生资产状态补回组合曲线，不进入标的贡献排名。

## 兼容与迁移

- 不新增数据库字段，不改写历史流水。
- `Snapshot` 是派生缓存；上线后重建快照即可应用新口径。
- 已有黄金现金结算腿继续按内部交易处理；无结算腿历史记录自动获得兼容语义。
- 本决策部分替代 ADR-003 中“所有手动估值资产均不可投资”的表述，双财富口径本身保持不变。

## 后果

- 黄金会同时出现在可投资资产、市场流动性、利润贡献与风险结构中。
- 手动估值黄金没有盘中行情时仍不会伪造实时价格；只有估值来源和新鲜度标签与市场报价资产不同。
- 外币现金或外币资产即使标的价格未更新，只要历史汇率发生变化，也形成汇率收益观察，避免金额归因残差。

## 验证

- 单测覆盖手动估值黄金的可投资/流动性口径、无结算腿外部资金流、有结算腿内部守恒、黄金买卖与估值回放。
- 复盘使用同源日序列后，组合收益、标的贡献和在途资金金额守恒；本地真实数据的待对账差额回到匹配阈值内。
