# Compound Life 交互稿评审记录

日期：2026-11-26。状态：设计候选，等待用户确认。

## 改版思路

| 变化 | 原因 | 预期改善 |
| --- | --- | --- |
| 手绘、胶带、虚线改为中性表面和细分隔线 | 装饰与数据竞争注意 | 长期阅读更稳定，红绿和警告色保留业务含义 |
| 大标题与摘要压缩为紧凑层级 | 当前持仓明细进入首屏过晚 | 更快进入资产比较；原型在1280px下表头顶端约417px，其中含评审工具条 |
| 净资产、可投资资产和负债分列 | 三者范围不同 | 看家底与看投资不混淆 |
| 区间结果保留收益对账行 | 资产变化不全是收益 | 一眼看到期初、净投入、投资收益和期末的关系 |
| 估值日期、来源和异常靠近数字 | 独立说明区需要来回寻找 | 更容易判断某个金额是否可用 |
| 中文短名与说明分层 | 过长文案影响扫读，过短标签又会失真 | 主界面简洁，必要范围与状态仍可见 |
| 四组真实字体直接切换 | 图片不能保证准确的字体渲染 | 对比同字号、同字重的中文、英文与金额 |

## 本轮实际验证

- 六项主导航均可切换；1280px下六页文档级横向溢出均为0。
- 总览在736px与320px下无文档级横向溢出；320px字体对话框及D方案无横向溢出。
- 总览切换本周后收益为2,000、净投入20,000、期初1,838,000、期末1,860,000，收益对账成立。
- 持仓按基金与“全球”关键词筛选后只显示匹配标的；点击名称可查看成本、数量和来源，继续进入匹配流水。
- 演示录入1,200元沪深300ETF后，新增行出现在演示流水列表，正式资产汇总不变。
- 基金确认份额1,900不匹配时显示校验错误；修正为2,000后完成流程演示，不写正式账本。
- 复盘笔记在步骤切换后保留；目标每月投入从2,000改为5,000后预计达成时间相应提前。
- 主题按钮可切换深色，持仓页深色截图已核对。
- Inter、Geist、Noto Sans SC均实际载入；A/B/D切换行为已检查，C与其他方案共用同一选择逻辑。
- 最新浏览器页面没有捕获到控制台错误；脚本语法检查通过。
- 演示持仓合计、可投资资产、净资产、在途资金、区间收益桥与盈亏贡献已核对。

## 交付范围

这是独立设计原型，不调用业务API或数据库。页面数据为虚构样本；录入、份额确认、笔记和目标试算均用于体验交互。CSV只导出演示持仓。刷新后演示数据恢复。

低频导入目前只展示流程入口；正式只读权限、加载、网络失败、完整字段、深链和生产财务计算还需在确认设计后细化。此原型的校验不能替代正式基金确认服务。

正式前端、财务引擎、数据库、配置、依赖和accepted ADR未改动，因此本轮未运行应用的全量单测、构建或E2E；原型已按以上范围单独验证。
