# Compound Life 实现与验收

2026-11-26，按用户确认的模板方向、Compound Life 品牌和 D 字体完成正式 Web 重构。本次是现有业务组件的视觉与文案迁移，未另建业务前端。

## 已落地

| 改动 | 改进 |
| --- | --- |
| Inter Variable + Noto Sans SC Variable 本地托管 | 英文、数字与中文风格一致，不依赖运行时 Google 字体请求；金额保留等宽数字 |
| 中性画布、黑白操作、细线分隔与轻量圆角 | 移除手绘装饰，减少长期使用时的视觉干扰，浅深主题一致 |
| 总览拆分家庭资产和投资表现 | 家庭资产展示负债、净资产走势和可展开的资产构成。投资表现展示可切换曲线、账户金额、年度收益对比和可展开的区间对账 |
| 持仓摘要与筛选收紧 | 1440×1000 隔离实页中表头约在 535px，首屏可见更多持仓；长名称可换行，全部列及横滚保留 |
| 中文标题和说明精简 | 周期复盘、收益归因、交易回顾、风险变化、复盘笔记；家庭角色使用中文 |
| 目标情景标题与数值匹配 | 将显示金额的结果区称为“目标日资产情景”，分别标明 P10/P50/P90；预计投资收益与本金分开 |
| 共享控件与错误页同步 | 搜索、主题切换、表单、只读提示、手动估值展开和根级错误页采用同一视觉方向 |

六项主导航、URL、筛选排序、导出、真实录入、基金确认、定投核对、复盘保存与目标试算均沿用已有实现。账本、引擎、行情源、Prisma、家庭作用域、写入权限及审计链未改。

## 验证

- `npm test`：100 文件，733/733 通过。
- `npm run build`：生产构建与 TypeScript 检查通过。
- `npm run test:e2e`：隔离种子库，198/198 通过。
- `git diff --check`：通过。
- 24 个主要路由在浅深主题、1280/1440/1600/1920px 下无页面级溢出或工具栏重叠；原有窄屏兜底、键盘、只读与跨家庭回归通过。
- 浏览器目视核对总览、资产、投资、记录、复盘与目标；确认实际字体、本地加载、主题切换、完整金额、表格与证据入口。

验证过程中更新了旧标题/按钮的文案断言，并按固定首屏门槛调整持仓间距；没有删除失败用例或放宽原有财务断言。既有汇率单测需要访问真实汇率源，最终在正常网络环境下全量通过。
