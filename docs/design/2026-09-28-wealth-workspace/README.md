## 设计方向

- 浅色、蓝色交互、深灰数字；家庭净资产与可投资收益分区。
- 6 个主导航候选；本轮实现总览、资产、记录，其余禁用并标明后续。
- 首屏保留待办直达；持仓筛选、排序、密度切换与详情抽屉；定投按账户分组，按实际买入 / 未买入 / 稍后核对分别处理。
- 退休 / 财富示例使用家庭净资产口径；长期资产仍不混入投资绩效。
- 1280px 以上为主要设计范围，额外提供平板与窄屏兜底。窄屏通过顶部搜索切页。
